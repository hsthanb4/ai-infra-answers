推理与选型

  • 24GB 显卡能跑 7B 大模型吗？先算权重和 KV Cache用权重、KV Cache 和运行开销三份账本判断 24GB 显存能否承载 7B 模型推理，并给出最小验证步骤。
  • KV Cache 显存怎么算？GQA、上下文和并发分别影响什么从层数、KV 头数、头维度、缓存精度和 token 数估算 KV Cache，区分理论张量大小与引擎实际分配。
  • 上下文长度和并发怎么设？大模型服务显存不足排查区分模型支持的最大长度、请求实际长度与服务并发，逐步定位长上下文推理的显存和延迟瓶颈。
  • vLLM 和 SGLang 怎么选？按真实请求做同条件比较用模型支持、前缀复用、结构化输出和服务指标比较 vLLM 与 SGLang，不用单个跑分替代业务验证。
  • 4bit 量化一定更快吗？显存、精度和算子支持怎么取舍解释低比特权重为何能省显存却不保证提速，以及选择量化方案前需要验证的精度与硬件条件。
  • 大模型首字延迟很高怎么办？先拆排队和 Prefill把首字等待拆成网络、排队、预填充和生成环节，找到 TTFT 变慢的实际位置。
  • 每秒 token 高就更快吗？推理吞吐与用户延迟怎么比较区分总吞吐、首字延迟和逐 token 延迟，用相同请求分布判断模型服务性能。
  • 前缀缓存能省多少计算？什么请求适合 Prefix Caching说明前缀缓存复用什么、不复用什么，以及怎样对比冷缓存、热缓存与真实业务命中率。

训练与排障

  • 7B 模型训练需要多少显存？112GB 静态账本怎么来的逐项计算 Adam 训练的参数、梯度与优化器状态，说明静态 112GB 与实际训练峰值的区别。
  • LoRA 和全参数微调怎么选？24GB 显卡先验证哪些条件区分低秩适配与全参数训练的状态开销，说明 QLoRA、序列长度和激活显存的影响。
  • 梯度累积能省多少显存？有效 Batch Size 怎么算用微批次、数据并行副本数和累积步数计算有效批量，解释梯度累积的收益与等价性边界。
  • 激活重计算是什么？什么时候值得用算力换显存解释 Activation Checkpointing 的重算成本、显存收益以及开启后的正确性检查。
  • ZeRO-1、2、3 和 FSDP 怎么选？先看切分了哪份状态比较优化器、梯度与参数分片，说明 ZeRO 与 FSDP 在显存、通信和维护成本上的取舍。
  • Ring AllReduce 通信量怎么算？2(N−1)/N 从哪里来推导环形规约每卡通信量，区分发送量、收发总量与真实端到端耗时。
  • NCCL 超时怎么排查？先找第一个出错的 Rank区分通信故障、进程提前异常与 collective 不匹配，给出 NCCL 超时的逐步诊断顺序。

算子与面试

  • CUDA 和 Triton 先学哪个？按目标岗位安排学习顺序比较 CUDA 与 Triton 的编程抽象和调试需求，为算子开发与 AI Infra 面试选择起点。
  • FlashAttention 为什么省显存？它改变了注意力公式吗解释 FlashAttention 的分块与在线 Softmax，区分精确注意力、存储节省与不同长度下的速度收益。
  • CUDA 合并访存是什么意思？连续线程该怎么读数据从线程访问地址与内存事务解释合并访存，区分全局内存布局和共享内存 Bank Conflict。
  • GPU Occupancy 越高越好吗？寄存器和块尺寸怎么调解释活跃 Warp 比例与实际性能的区别，避免为提高 Occupancy 造成寄存器溢出或重复计算。
